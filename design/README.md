# design

Analog blocks, one directory each, with schematic, symbol, derived netlist and
a `SIZING.md` that traces every size to the spec or a decision record.
`xschemrc` is the project xschem configuration (`klt netlist --rcfile design/xschemrc`).

- `ota/` — fully-differential folded-cascode OTA with CMFB (issue #38).
- `integrator/` — SC integrator and 1-bit feedback DAC, instantiating the OTA (issue #40).
- `clkgen/` — non-overlapping two-phase clock generator, `phi1 phi1b phi1e phi2` (issue #41).
- `modulator/` — top-level second-order single-bit modulator wiring two integrators, the comparator, an SR latch and the clock generator (issue #41); `modulator/comparator/` is the vendored `sky130-comparator` with provenance.

## Regenerating netlists

Netlists are derived, never hand-edited; `--check` exits 0 on `match`, 3 on `drifted`.

    klt netlist design/clkgen/clkgen.sch -o design/clkgen/clkgen.spice --rcfile design/xschemrc --block
    klt netlist design/modulator/modulator.sch -o design/modulator/modulator.spice --rcfile design/xschemrc --block
    design/modulator/comparator/wrap_comparator.sh

Add `--check` (or `wrap_comparator.sh --check`) to gate drift. The vendored
comparator schematic needs xschem >= 3.4.5 to be re-netlisted (`expr()`);
see `modulator/comparator/PROVENANCE.md` for the pin, how it was fetched, and
what is checked.

## Digital partition, T1 item 1 (design sources)

- Sources: `rtl/decimator.v`, `rtl/decimator_coef.v` (generated by
  `verification/decimator/design_fir.py`).
- Derived: `rtl/netlist/decimator_synth.v`, the Yosys-synthesized `sky130_fd_sc_hd`
  gate-level netlist (`klt synthesize`, `tt_025C_1v80`). Synthesis only, no timing, not measured.
- Inventory: `attest/item1-digital-inventory.json`; envelope: `attest/item1-digital-envelope.json`;
  cited in the manifest as `"1.digital"`.

Regenerate after any RTL change (needs the pinned PDK from `sim/pdk.json` and Yosys):

```
python3 design/attest/check_digital_netlist.py --update      # refresh the netlist
uvx --from "klayout-tools==$(cat .github/klt-version)" klt signoff --attest 1 \
    --inventory design/attest/item1-digital-inventory.json -o design/attest/item1-digital-envelope.json
```

then update the `content_hash` for `1.digital` in `manifests/sky130-sigma-delta-adc.json` (the inventory
hash, `provenance.input.content_hash` in the envelope) and regenerate the verdict of record as
described in `.github/workflows/signoff.yml`.

The freshness check (`check_digital_netlist.py`) is `local_only`: CI does not re-synthesize, it
checks the committed envelope's hashes. Running the check script without `--update` exits 3 when the
committed netlist is stale.
